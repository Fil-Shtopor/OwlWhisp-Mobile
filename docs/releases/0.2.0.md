# OwlWhisp Mobile 0.2.0

- App update checks on launch, a new-version offer and manual checks in Settings.
- Android downloads verify the release checksum, package, version and signing identity before opening the system installer.
- iOS offers the GitHub release and unsigned IPA; each update still requires personal Apple signing.
- An optional experimental language switch in the Android voice panel and iOS Dictate. Assign a model per language in Settings, then switch between recordings. It is hidden when disabled.
- Compact model cards with saved WER/RTF by language. Benchmarking another model preserves previous model results.
- A shared phone/language model guide with detected memory class, common phone profiles and task priorities. Suggestions are starting points; performance figures come only from device benchmarks.

Install this version manually once to enable checks for future releases. Android uses the existing release signing identity and updates 0.1.x installations.

## Downloads

- Android: signed ARM64 / x86_64 APK, Android 9+.
- iPhone / iPad: unsigned ARM64 IPA, iOS 16+. [Personal signing is required](https://github.com/Fil-Shtopor/OwlWhisp-Mobile/blob/main/ios/README.md#personal-signing-from-windows-or-macos).
- iOS Simulator: app ZIP for macOS/Xcode.

Models download separately. Physical phone performance still needs validation.
