# OwlWhisp Mobile 0.1.7

- Android model downloads now use a foreground data-sync service, keeping the transfer active across app tabs, activity recreation, app switching and screen lock.
- Download progress and Cancel are available on every Android tab and in the download notification. The service stops after completion, cancellation or failure.
- Model recommendations are explicitly labeled as suggestions. Filters do not select or download a model automatically.
- Recommended models show their download size and a direct Download button on Android and iOS. Progress stays visible in the recommendations; after verification, choose Use model.
- Retrying an interrupted download reuses verified files. Incomplete or corrupt files are never installed.

Android uses the existing release signing identity and updates previous 0.1.x installations.
Version 0.1.6 can discover this release through Settings > App updates.

## Downloads

- Android: signed ARM64 / x86_64 APK, Android 9+.
- iPhone / iPad: unsigned ARM64 IPA, iOS 16+. [Personal signing is required](https://github.com/Fil-Shtopor/OwlWhisp-Mobile/blob/main/ios/README.md#personal-signing-from-windows-or-macos).
- iOS Simulator: app ZIP for macOS/Xcode.

Models download separately. iOS supports navigation within the app during downloads; persistent iOS background downloads are not added in this release. Physical phone validation is still needed.
