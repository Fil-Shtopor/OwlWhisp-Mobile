# OwlWhisp Mobile 0.1.5

The Benchmark tab on Android and iOS now uses a compact results view:
- Clip counts by language for the selected model.
- Overall word error rate (WER), processing-to-audio ratio (RTF), audio duration and processing time.
- No sample sentences, raw JSON or dataset descriptions in the main screen.

Overall WER is weighted by reference word count; RTF uses total processing time divided by total audio duration. Existing Android benchmark reports also use the new summary. Full per-clip measurements and transcripts remain available through Share report (and Copy report on Android). Dataset attribution remains in the bundled notices and repository documentation.

Benchmark exports now include aggregate metrics and the installed app version. Recognition and recording behavior are unchanged.

## Downloads

- **Android:** signed ARM64 / x86_64 APK, Android 9+. Updates the existing app.
- **iPhone / iPad:** unsigned ARM64 IPA, iOS 16+. Personal Apple signing is required before installation; see [installation instructions](https://github.com/Fil-Shtopor/OwlWhisp-Mobile/blob/main/ios/README.md#personal-signing-from-windows-or-macos).
- **iOS Simulator:** app ZIP for macOS/Xcode, not for installation on an iPhone.

Models download separately. Physical iPhone behavior has not been validated.
